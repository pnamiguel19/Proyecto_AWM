### 🎯 Descripción del objetivo de la práctica

El objetivo central de esta práctica es la implementación de *JavaScript* para dotar de *interactividad* dinámica al prototipo de *EduMatch*. Se busca evolucionar la maquetación estática previa hacia una aplicación funcional, aplicando lógica de programación para controlar el comportamiento de la interfaz.

Para lograr esto, el desarrollo se enfocó en:

* *Programación de Eventos y DOM:* Implementar código JavaScript que escuche y responda a las acciones del usuario (clics, cambios de input, scroll), manipulando el DOM para modificar la interfaz en tiempo real sin recargar la página.
* *Validación de Formularios:* Desarrollar scripts para verificar la integridad de los datos en el lado del cliente (Login, Registro de Profesores, Contacto), asegurando que la información cumpla con los formatos requeridos antes de ser procesada.
* *Simulación de Funcionalidad:* Utilizar JavaScript para simular el envío de datos y la respuesta del servidor (mediante alerts o console.log), demostrando el flujo lógico completo de la aplicación según el modelo de negocio planteado.

## 💡Recomendaciones:
### Miguel Avilez
- Se recomienda mantener el código JavaScript organizado y separado del HTML mediante archivos externos, para mejorar la legibilidad y facilitar el mantenimiento del proyecto. Además, es buena práctica comentar las secciones importantes del código para que otros desarrolladores comprendan fácilmente su funcionamiento.
- Es aconsejable optimizar las funciones de JavaScript evitando el uso excesivo de scripts innecesarios que puedan afectar el rendimiento del sitio. También se sugiere probar la interactividad en diferentes navegadores y dispositivos, garantizando así una experiencia consistente y accesible para todos los usuarios.
### Jannys Garrido
- Es aconsejable aplicar técnicas de diseño responsivo desde las primeras etapas del desarrollo, utilizando sistemas de cuadrículas flexibles, tipografía escalable y componentes reconfigurables según el tamaño de pantalla.
- Es aconsejable mantener una coherencia visual en todos los mockups, respetando la paleta de colores institucional, la tipografía seleccionada y el estilo de los íconos. Esta uniformidad refuerza la identidad visual de EduMatch y genera confianza en los usuarios.
